# 🔤 Buchstaben-Memory

Ein kinderfreundliches Memory-Spiel zum Zuordnen von Groß- und Kleinbuchstaben (A/a bis Z/z).

## Spielen

Öffne `index.html` im Browser. Wähle 6, 12 oder 26 Buchstabenpaare. Decke jeweils zwei Karten auf und finde die passenden Groß- und Kleinbuchstaben.

## GitHub Pages

In den Repository-Einstellungen unter **Settings → Pages** als Quelle **Deploy from a branch**, Branch **main** und Ordner **/(root)** auswählen und speichern.

Keine Installation und keine externen Abhängigkeiten nötig.
